## 残作業: 修正すべき機能 (Fix)

- [ ] **M2: リフトの非対称クリップによる過大評価** （コスト: 小 / 実害: 中）
      `step1` の `clip(≥0)` で非特売日の負ノイズ（合計 -20,321）が潰され正ノイズ（+20,412）だけ残り、リフトを構造的に +4〜6% 過大評価。`ground_truth` 照合で Lift総量比 104〜106%、偽リフト割合 約4〜5% として実証済み。
      → 対策案: クリップ前の対称リフトで総量を保存する補正、または非特売日のベースラインをリフトに含めない明示マスク。
      影響: 販促ROI・増分粗利・弾力性カーブの絶対値が一律に膨らむ。

- [ ] **M4: バイアス指標の欠如** （コスト: 小 / 実害: 小〜中）
      WAPE/MAPE は誤差の方向（過大=過剰在庫 / 過小=欠品）を打ち消す。systematic bias（`sum(pred-actual)/sum(actual)`）を `calculate_metrics` か検証レポートに追加し、ダッシュボードの精度パネルに表示する。
      （注: `scripts/validate_decomposition.py` には Base Bias% を既に実装済み。予測側にも展開する。）

## 既知の限界 (Known limitations / 改善余地)

- [ ] **信頼区間が特売日・非特売日で均一** — M1 のキャリブレーションは残差分布を期間一律と仮定。実際は特売日の誤差が大きいため、条件付きバンド幅（conditional / weighted conformal）が理想。
- [ ] **信頼区間は in-sample キャリブレーション** — バックテスト残差を同じバックテストに当てているため、表示カバレッジ（80%）は将来期間ではやや低めに出る。真の将来カバレッジ評価には A6（walk-forward）が前提。

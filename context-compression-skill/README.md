# Context Compression Skill

ツール出力をコンテキストウィンドウに入れる**前**に圧縮・フィルタするための指示書（rtk-ai/rtk の発想を踏襲）。スクリプトは持たず、SKILL.md 単体でエージェントの振る舞いを規律する。

| Document | Purpose |
|----------|---------|
| [SKILL.md](SKILL.md) | 本文（10原則・ツール語彙対応表・アンチパターン変換表・圧縮しない場面・安全弁） |

## 使われ方

- **中核ルールは常時適用のグローバル指示に置く**: `~/.claude/CLAUDE.md` と `~/.gemini/GEMINI.md` の「コンテキスト圧縮」節に10行程度の要約がある。毎ターン効かせたい作法はスキル（必要時ロード）では発動が不安定なため。
- **本スキルは詳細リファレンス**: ビルド・テスト・巨大ファイル・表データ・広域検索・Web 調査など、大量出力が見込まれる場面で読み込まれる。
- Claude Code / Gemini CLI 両対応。本文は汎用語彙で書き、実ツール名は SKILL.md 冒頭の対応表で読み替える。

## 設計上の要点

- **終了コードを落とさない**: Bash の `cmd | tail -30` は失敗を exit 0 に見せるため、ログファイル経由 + `echo "exit=$ec"` を正規形とする。
- **圧縮しない場面を明記**: レビュー・監査・バグ原因特定・Edit 用文字列作成・事実検証では、断片ではなく関数/ファイル単位で通読する。
- **サブエージェントの結果は未検証扱い**: 返されたパス・ID・名前は使う前に実在確認する。

原則の一覧・具体例は [SKILL.md](SKILL.md) を参照（README には複製しない）。

# AI SCM戦略提案 - Before/After プレビュー機能

**作成日:** 2026-02-23
**バージョン:** 2.1.0
**機能:** Real-time Impact Preview in AI Consultant Tab

---

## 📊 概要

**Tab7: AI SCM戦略提案**に、改善目標のインパクトを**リアルタイムでプレビュー**する機能を追加しました。

スライダーを動かすだけで、Before（現状）とAfter（改善後）の比較が即座に表示されます。

---

## 🎯 改善内容

### **Before（改善前）**

```
Tab7: AI SCM戦略提案
├─ 分析オプション（チェックボックス）
├─ 改善目標設定（スライダー2つ）
│   ├─ 売上原価率 削減目標
│   └─ CCC 改善目標
└─ 🤖 AIコンサルタントに戦略立案を依頼（ボタン）
```

**問題点:**
- ❌ スライダーを調整しても、結果が見えない
- ❌ ボタンを押すまでインパクトが分からない
- ❌ AI実行（遅い）しないと効果が確認できない

## 🎨 表示内容詳細

### **1. Before / After メトリクス比較**

左右2カラムで現状と改善後を並列表示:

#### **Before（現状）**
```
📉 Before（現状）

売上原価率        営業利益率
65.0%            15.0%

営業利益          CCC
15,000M          75日
```

#### **After（改善後）**
```
📈 After（改善後）

売上原価率        営業利益率
63.0%            17.0%
▼ -2.0pp         ▲ +2.0pp

営業利益          CCC
17,000M          60日
▲ +2,000M        ▼ -15日
```

**特徴:**
- ✅ st.metric() で変化量（△）を自動表示
- ✅ 改善は緑、悪化は赤で色分け
- ✅ `delta_color="inverse"` で売上原価率とCCCは減少が改善

---

### **2. 改善インパクトサマリー**

3つの主要指標を横並びで表示:

```
💡 改善インパクトサマリー

営業利益 増加額    運転資本 削減額    総合インパクト
+2,000M           +2,740M           +4,740M
```

**計算ロジック:**

#### 営業利益増加額
```python
sim_oi_ai = current_revenue_ai - sim_cogs_ai - current_opex_ai
営業利益増加額 = sim_oi_ai - current_oi_ai
```

#### 運転資本削減額
```python
working_capital_reduction_ai = (ccc_reduction / DAYS_PER_YEAR) * current_cogs_ai
```

**例:**
```
CCC 15日短縮 × (売上原価 65,000M / 365日) = 2,671M削減
```

#### 総合インパクト
```python
総合インパクト = 営業利益増加額 + 運転資本削減額
```

---

### **3. Before / After 比較チャート**

棒グラフで3つの評価軸を比較:

```
📊 Before / After 比較チャート

評価軸:
1. 営業利益率 (%)     → Before: 75点, After: 85点
2. CCC (日)           → Before: 25点, After: 40点
3. 運転資本効率       → Before: 50点, After: 65点

※スコアは0-100に正規化
```

**スコア計算:**

```python
# 営業利益率: 1% = 5点
営業利益率スコア = 営業利益率 × 5

# CCC: 短いほど高得点（100 - CCC日数）
CCCスコア = max(0, 100 - CCC日数)

# 運転資本効率: 削減額に応じて加点
運転資本効率スコア = 50 + (削減額 / 売上高 × 100) × 10
```

**ビジュアル:**
- 🟠 Before（現状）: オレンジ色の棒
- 🟢 After（改善後）: グリーン色の棒
- 数値ラベル付き（棒の上に表示）

## 🔧 技術実装

### **リアルタイム更新の仕組み**

```python
# スライダーの値が変更されると、Streamlitが自動再実行
cogs_reduction = st.slider("売上原価率 削減目標 (%)", 0.0, 10.0, 2.0, 0.5)
ccc_reduction = st.slider("CCC 改善目標 (日)", 0, 60, 15, 5)

# スライダー直後のコードが即座に実行される
sim_cogs_ratio_ai = current_cogs_ratio_ai - cogs_reduction
sim_ccc_ai = current_ccc_ai - ccc_reduction

# st.metric() で差分を自動計算＆表示
st.metric(
    "営業利益率",
    f"{sim_oi_margin_ai:.1f}%",
    f"{(sim_oi_margin_ai - current_oi_margin_ai):+.1f}pp"  # △を自動計算
)
```

---

### **delta_color="inverse" の活用**

```python
# 通常: 増加=緑、減少=赤
st.metric("営業利益", value, delta)

# 逆転: 減少=緑、増加=赤（コスト系指標）
st.metric("売上原価率", value, delta, delta_color="inverse")
st.metric("CCC", value, delta, delta_color="inverse")
```

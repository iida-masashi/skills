## 🎯 この機能でできること

企業の収益構成を**事業セグメント別**と**地域別**に分析できます。

**例:**
- Apple: iPhone (52%), Services (22%), Mac (8%), ...
- トヨタ: 自動車 (90%), 金融 (7%), その他 (3%)
- ソニー: ゲーム (30%), エレクトロニクス (25%), 音楽 (11%), ...

---

## 🚀 使い方（3ステップ）

### **Step 1: 企業を選択**

サイドバーで分析したい企業を選択:

```
企業名 または ティッカー: Apple
```

または

```
企業名 または ティッカー: トヨタ
```

---

### **Step 2: Tab8を開く**

タブバーから「📊 8. 事業セグメント分析」をクリック

---

### **Step 3: 結果を確認**

自動的に以下が表示されます:

✅ **事業セグメント別 収益構成**
- パイチャート（全体像）
- データテーブル（詳細数値）
- 棒グラフ（セグメント比較）
- コンサルタントの診断（リスク評価）

✅ **地域別 収益構成**
- パイチャート（地域分布）
- データテーブル（地域詳細）

## 🤖 AI自動抽出モード（未登録企業向け）

### **いつ使う？**

- 分析したい企業が上記リストにない場合
- 最新のセグメント情報が欲しい場合

### **使い方**

1. Tab8を開く
2. ☑ 「AI自動抽出を使用 (Gemini API)」にチェック
3. 自動でGemini AIが最新の10-K/有価証券報告書からセグメント情報を抽出

**注意:**
- Gemini APIキーが必要（.envファイルで設定）
- 抽出精度はAIに依存（要検証）

## 💡 診断結果の読み方

### **集中リスク判定**

#### 🔴 高リスク（最大セグメント50%超）

```
💡 Consultant's Insight: 🔴 高リスク
収益の52.0%を「iPhone」に依存しているわ。集中リスクが高すぎるわね。
他セグメントの育成が急務よ。
```

**意味:**
- 単一事業への依存度が極めて高い
- その事業が不調になると企業全体が危機に
- 多角化・新規事業育成が必要

---

#### 🟡 中リスク（最大セグメント30-50%）

```
💡 Consultant's Insight: 🟡 中リスク
「Intelligent Cloud」が42.0%を占めているわ。主力事業としては健全だけど、
多角化余地はあるわね。
```

**意味:**
- 主力事業は明確だが、依存度は許容範囲内
- さらなる多角化で安定性向上の余地あり

---

#### 🟢 分散良好（最大セグメント30%未満）

```
💡 Consultant's Insight: 🟢 分散良好
事業ポートフォリオは比較的バランスが取れているわ。リスク分散できてるわね。
```

**意味:**
- 複数事業がバランス良く収益を上げている
- 特定事業の不調でも企業全体への影響は限定的
- 理想的なポートフォリオ

## 🔧 カスタム企業の追加方法

自社や非公開企業のセグメント情報を手動で登録できます。

### **手順**

1. Tab8の一番下「🔧 カスタムセグメント登録」を展開
2. 以下を入力:
   - ティッカーシンボル（例: 5988.T）
   - 企業名（例: パイオラックス株式会社）
   - セグメントJSON（下記例参照）
   - 会計年度（例: 2023）
3. 「登録」ボタンをクリック

### **JSON例**

```json
{
  "自動車部品": {
    "percentage": 0.85,
    "description": "ファスナー、エアダンパー"
  },
  "医療機器": {
    "percentage": 0.10,
    "description": "カテーテル"
  },
  "その他": {
    "percentage": 0.05,
    "description": "新規事業"
  }
}
```

**注意:**
- `percentage` の合計は 1.0 (100%) になるようにしてください
- 小数点形式（0.85 = 85%）

## 🎓 よくある質問（FAQ）

### **Q1: セグメントデータが「取得できません」と表示される**

**A:** 以下を試してください:

1. ✅ 「AI自動抽出を使用」をONにする
2. ✅ カスタム登録フォームで手動登録する
3. ✅ 別の企業（対応済み企業）で試す

---

### **Q2: 地域別データが「利用できません」と表示される**

**A:** その企業の地域別マッピングがまだ未登録です。

**対処法:**
- 主要企業（Apple, Microsoft等）のみ地域別データあり
- 今後のアップデートで対応企業を拡大予定

---

### **Q3: AI抽出が失敗する**

**A:** 以下を確認してください:

1. ✅ .envファイルに `GOOGLE_API_KEY` が設定されているか
2. ✅ Gemini APIの無料枠制限（1分間15リクエスト）に達していないか
3. ✅ インターネット接続が安定しているか

---

### **Q4: セグメント情報が古い**

**A:** 手動マッピングはFY2023時点のデータです。

**最新情報が必要な場合:**
- ✅ AI自動抽出モードを使用
- ✅ カスタム登録で最新データを手動入力

## 📊 活用シーン

### **1. 投資判断**

```
例: Appleへの投資を検討
→ iPhone依存度が52%と高い
→ Services（22%）が成長中だが、まだiPhone依存
→ iPhone市場の成長鈍化リスクを考慮
```

---

### **2. 競合分析**

```
例: Microsoft vs Google vs Amazon
→ Microsoftはクラウド42%、生産性34%とバランス良好
→ Googleは検索・広告88%と集中リスク高
→ AmazonはEC42%、AWS16%、マーケットプレイス24%と分散
```

---

### **3. 業界トレンド把握**

```
例: 自動車メーカーの金融事業比率
→ トヨタ: 金融7%
→ 他社と比較して金融事業の重要性を評価
```

---

### **4. M&A・事業再編の検討**

```
例: 自社の事業ポートフォリオ
→ セグメントAが5%のみ（撤退候補）
→ セグメントBが60%（集中リスク、多角化必要）
→ セグメントCが成長中だが利益率低い（改善必要）
```

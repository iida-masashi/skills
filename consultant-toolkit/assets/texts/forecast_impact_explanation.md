## 需要予測精度向上によるインパクト計算式

需要予測の精度（Forecast Accuracy）が向上することで、安全在庫を圧縮し、それに付随する在庫保管コストを削減することで、直接的に営業利益を向上させるロジックです。

---

### 1. 在庫削減率の算出

需要予測精度の向上幅に、在庫削減への感応度（マルチプライヤー）を乗じて計算します。

```
在庫削減率 (%) = 需要予測精度の向上率 (%) × 予測向上1%あたりの在庫削減係数
```
*   **需要予測精度の向上率**: AI導入等によるマディ（予測誤差）の改善幅。
*   **在庫削減係数**: 予測精度が上がった際に、どれだけ安全在庫を攻めて減らせるかを示す係数（実務的には0.5〜1.0程度が一般的）。

---

### 2. 在庫削減金額の算出

現在の在庫残高に、算出した在庫削減率を適用します。

```
在庫削減額 = 現在の在庫残高 × 在庫削減率 (%)
```

---

### 3. 在庫保管コスト削減額（営業利益改善額）の算出

削減された在庫に対して、年間の在庫保管コスト率（Holding Cost Rate）を乗じます。在庫が減ることで、倉庫代、保険料、陳腐化リスク、資本コストが削減され、その分が**そのまま営業利益のプラス**となります。

```
コスト削減額 (営業利益改善額) = 在庫削減額 × 在庫保管コスト率 (%)
```
*   **在庫保管コスト率**: 一般的に製造業では在庫金額の15%〜25%程度と言われています。

---

### 4. 改善後の営業利益率

```
改善後の営業利益 = 現在の営業利益 + コスト削減額
改善後の営業利益率 (%) = 改善後の営業利益 ÷ 売上高 × 100
```

> **SCMコンサルの視点**: 需要予測の改善は、単なる「ハズレ」を減らすだけでなく、キャッシュフローの改善（運転資本の解放）と、PL（営業利益）の改善の両面に絶大なインパクトをもたらします。

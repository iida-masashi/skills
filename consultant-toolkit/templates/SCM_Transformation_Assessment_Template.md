# 【コンサルティング・テンプレート】SCM再構築・需給ガバナンス改革 診断＆設計フレームワーク

本テンプレートは、消費財（FMCG）・化粧品・製造業におけるサプライチェーン再構築、在庫適正化（DIO削減・SLOB撲滅）、および需給ガバナンス改革プロジェクトを推進する際の標準診断・設計フレームワークである。

---

## 1. 改革の北極星（North Star KPIs）

| KPI指標 | 現状（As-Is） | 目標（To-Be） | 期待創出効果 |
| :--- | :--- | :--- | :--- |
| **DIO（在庫回転日数）** | [例: 150日] | [例: 100日以下] | 運転資本・キャッシュ創出 [XX億円] |
| **SLOB（滞留・廃棄損率）** | [例: 売上比 4%] | [例: 1.5%以下] | 売上総利益・営業利益改善 [XX億円] |

## 2. 6大ワークストリーム別 診断項目マトリクス（Fact-Finding Matrix）

### WS1: 需要予測・S&OPガバナンス
- [ ] **FVA（Forecast Value Added）監査**: AI/統計ベースライン予測に対する営業・マーケの手修正による精度悪化率を算出。
- [ ] **デマンドバイアス分析**: 過去の新製品における売上予算 vs 実売の過大予測バイアスを測定。
- [ ] **S&OP牽制力評価**: 月次S&OP会議におけるSCM側の増産拒否権（Veto Power）の実効性を監査。

### WS2: 在庫構造・多層在庫最適化（MEIO）
- [ ] **多段在庫分解**: 原材料・未充填バルク・半製品・完成品の拠点別金額・数量構成比を算出。
- [ ] **安全在庫重複度測定**: 各エシェロン（中央DC・地域DC・店舗）における安全在庫の二重持ちをGSMモデルで定量化。
- [ ] **地域間・チャネル間融通性**: 法定ラベル・薬事・共通仕様の観点から在庫プーリングの実現余地を検証。

### WS3: SKUポートフォリオ・製品ライフサイクル（PLM）
- [ ] **ABC-XYZ / Dog SKU分析**: 売上貢献が極めて低く変動が激しい下位SKUの滞留在庫金額を特定。
- [ ] **新製品投入 vs 廃番純増率**: 過去3年間の新SKU上市数と廃番（EOL）数のバランスを測定。
- [ ] **One-In One-Out規律の有無**: 新製品上市時の同数廃番ルールの有無を確認。

### WS4: 生産・調達・形状遅延（Postponement）
- [ ] **バルク製造 vs 充填包装のリードタイム分離**: 共通容器・無地ボトルへの切替え余地を検証。
- [ ] **工場MOQ・段取り替え時間**: 多品種小ロット対応可能なセル生産ラインの導入可能性を評価。
- [ ] **特注容器/包材の調達リスク**: サプライヤーのリードタイム短縮余地を調査。

### WS5: IT・データ基盤（閉ループ需給連携）
- [ ] **マスターデータ整合性**: ERP、計画系（IBP/o9/OMP）、AIエンジン間のBOM・LTマスタ同期を確認。
- [ ] **POS実売（Sell-Out）日次連携**: 店頭・ECの実売データをAI需要予測にダイレクト連携できるか検証。

### WS6: 組織・人事評価制度（共同説明責任）
- [ ] **MBO評価へのDIO/SLOB連動**: 事業部長・マーケティング幹部が在庫責任を共有しているかを監査。
- [ ] **SCM部門の独立性**: プランナーおよび工場長のレポートラインがCOO/グローバルSCM本部に直属しているかを確認。

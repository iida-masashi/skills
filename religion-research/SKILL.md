# 文化人類学・民族誌研究 (religion-research) 専門スキルガイド

本スキルは、宗教だけでなく**食文化・音楽・土着の民族文化**まで対象を広げた、文化人類学的な調査・分析を標準化し、`D:\Vault\religion` Vault 配下に高品質かつ構造化されたObsidianナレッジグラフを構築・維持するための専門ガイドラインである。

> **経緯**: 本スキルは元々 `D:\tenri`（天理教専用Vault）→`D:\Vault\religion`（宗教研究全般Vault）の調査に特化していたが、対象を文化人類学一般（宗教・食文化・音楽・土着民族文化）へ拡張した。宗教分野の詳細な調査ノウハウ（教団構造分析・教理比較等）はそのまま活かしつつ、他の3領域にも通用する調査の型を用意している。スキル名・保存先Vaultは移行の経緯を踏まえて据え置いている。

---

## 🧭 基本指針と5大厳守ルール

分野が変わっても、文化事象を調査・記録する上で崩してはならない原則は共通している。

1. **一次情報主義 (`convMD`)**:
   - 教団・料理・楽器・儀礼等の解説ページ・学術論文・行政資料は、必ず `convMD` ツールを用いて `D:\Vault\religion` に直接 Markdown ファイルとして変換・保存する。
   - 実行コマンド例: `uv run python -m convmd.cli "<URL>" --obsidian-vault "D:\Vault\religion"`
2. **客観的・学術的研究視点**:
   - 正統・異端、伝統的・俗流、洗練・素朴といった価値判断を排除し、歴史的ファクト・現地調査記録・文献・学術研究（宗教学なら弓山達也・島薗進・井上順孝、食文化なら石毛直道、音楽なら小泉文夫、民族学なら綾部恒雄・祖父江孝男等の諸説）に基づき客観的に記録・比較する。
   - 分野を問わず「なぜその慣習が成立したか」を当事者側の論理（emic）と外部観察者側の分析（etic）の両方から捉え、どちらか一方だけを事実として断定しない。
3. **Wikilink basename ルールの徹底**:
   - wikilink は必ず **basename 形式** (`[[ほんみち]]`, `[[讃岐うどん]]`, `[[津軽三味線]]`) のみを使用し、`[[フルパス/X.md]]` のような絶対・相対パスは一切使用しない（赤リンク化リスク回避）。
4. **Dataviewブロックの排除（静的Markdown表の強制）**:
   - 公開サイト（Quartz等）での露出エラーを防ぐため、`` ```dataview `` クエリは使用せず、すべて**最初から静的なMarkdown表**として記述する。
5. **留保セクション（`> [!warning]`）とエビデンス明記の必須化**:
   - すべての専門ノートの最末尾に留保セクションを設置し、`evidence_type` と `confidence` (1-5) を明記する。特に食文化・音楽・民族文化は「地域ごとの言い伝え」「観光向けに脚色された説明」と学術的検証が混在しやすいため、出典の性質を明記することが宗教分野以上に重要になる。

## 🗂️ 対象4領域と参照ファイル

分野ごとに調査の観点・比較軸・注意点が異なるため、詳細は `references/` 配下に分けている。**調査対象を特定したら、まず対応する reference ファイルを読むこと。**

| 領域 | 対象の例 | 参照ファイル |
| :--- | :--- | :--- |
| **宗教** | 教団、分派・異端運動、教義概念、教祖・天啓者、教会拠点 | `references/religion.md` |
| **食文化** | 郷土料理、食習慣、儀礼食（祭祀・冠婚葬祭の食）、発酵・保存技術、食のタブー | `references/food.md` |
| **音楽** | 民族音楽、伝承歌謡（民謡・わらべ歌）、儀礼音楽（祭囃子・祈祷歌）、楽器、口承の伝承経路 | `references/music.md` |
| **土着の民族文化** | 親族制度、通過儀礼（成人式・婚姻・葬送）、工芸・生業技術、口承伝承（伝説・昔話）、村落共同体の慣習 | `references/ethnic-culture.md` |

複数領域にまたがる対象（例：特定教団の儀礼食、特定民族の祭祀音楽）は、どちらの reference にも目を通し、より深く分析したい軸を主に据える。迷う場合はユーザーに確認する。

## 📊 領域別比較軸セット

「10軸教理比較マトリクス」は宗教固有の設計だった（主祭神・甘露台等）。領域が変わればノートを特徴づける軸も変わるため、以下のように領域ごとに比較軸セットを分けている。詳細と記入例は各referenceファイルにある。

- **宗教**: 主祭神・神名、核心聖地、聖典・原典、天啓の継承、儀礼・つとめ、地方拠点形態、国家・皇室観、救済観、葬儀・祭祀、他教団との系譜関係（→ `references/religion.md`）
- **食文化**: 主要食材・産地、調理法・保存技術、供される場面（日常食／儀礼食／祝祭食）、地域内バリエーション、起源伝承、他地域の類似食との系譜、現代における継承状況（→ `references/food.md`）
- **音楽**: 使用楽器・編成、音階・リズム構造、伝承経路（口伝／楽譜／家元制）、演奏場面（労働歌／祭礼／娯楽）、地域内バリエーション、他地域の類似曲との系譜、保存会・継承者の現状（→ `references/music.md`）
- **土着の民族文化**: 対象となる制度・慣習の機能（社会統合／通過儀礼／生業）、担い手・継承者、儀礼の手順・象徴、地域内バリエーション、近隣文化との異同、近代化・過疎化による変容（→ `references/ethnic-culture.md`）

比較マトリクスは「対象 vs 周辺文化・母体文化」の対比を可視化するための道具であって、対象を序列化するためのものではない。優劣ではなく差異を記述する。

## 📂 Vault 構造標準 (`D:\Vault\religion`)

`D:\Vault\religion` は現状、宗教（`01_宗派・異端研究/`, `08_教会・系統研究/`）を中心にシャーディングされている。食文化・音楽・土着民族文化の新規ノートについては、**現時点でVault側に対応するトップフォルダをまだ用意していない**。

```
D:\Vault\religion/
├── 01_宗派・異端研究/        # 宗教（教団・分派・教理・人物）専用。詳細はreligion.md参照
├── 08_教会・系統研究/        # 個別教会・拠点の系統研究
├── templates/
│   ├── tpl_sect_note.md    # 教団調査用テンプレート（汎用宗教横断版）
│   ├── tpl_person_note.md  # 人物調査用テンプレート
│   ├── tpl_doctrine_note.md # 教理・概念調査用テンプレート
│   └── tpl_church_note.md  # 教会単位調査用テンプレート
└── (convMD変換済み一次情報MDファイル群)
```

食文化・音楽・土着民族文化のノートを新規作成する際は、**配置先フォルダをその都度ユーザーに確認する**（AskUserQuestion等で）。理由は、対象がどの粒度で今後増えるか（単発の調査で終わるのか、シリーズ化するのか）によって、独立トップフォルダを新設すべきか、既存構造に間借りさせるべきかが変わるため。黙って新規トップフォルダを作らない・黙って`01_宗派・異端研究/`直下に押し込まない。

一定数のノートが蓄積しシリーズ化が明確になった段階で、ユーザーと相談の上、宗教分野の`01_宗派・異端研究/`に相当するトップフォルダ（例：`02_食文化研究/`, `03_音楽研究/`, `04_民族文化研究/`）を新設し、当ドキュメントの「Vault構造標準」を更新する。

## 🛠️ 主なワークフロー

### 1. 新規対象の調査・作成（領域共通）
1. 対象の領域（宗教／食文化／音楽／土着民族文化、または複数領域にまたがる）を特定する。
2. 対応する `references/<領域>.md` を読み、その領域特有の調査観点・比較軸・注意点を確認する。
3. Web検索・学術文献で一次情報URLを取得する。
4. `convMD` で一次情報を `D:\Vault\religion` に直接Markdown変換取り込みする。
5. 共通12セクション構造（領域別の見出し言い換えは reference 参照）に従ってノートを作成する。配置先フォルダは上記「Vault構造標準」に従いユーザーに確認する。
6. 関連するハブ・一覧ノートがあれば `[[basename]]` リンクを追加する。ハブが無い領域・対象であれば、新設要否をユーザーに確認する（宗教分野の `_分派・異端研究ポータル` に相当するものがまだ無いため）。

### 2. 人物調査（伝承者・職人・演奏者・教祖等）
1. 対象人物について調査する。
2. `tpl_person_note.md` の考え方（宗教の天啓者向けだが、職人・演奏者にも項目を読み替えて流用可能）に基づき12セクションノート化し、所属・関連する対象ノートと `[[wikilink]]` で紐付ける。

### 3. 比較・概念分析
1. 「甘露台」（宗教）、「郷土料理の系譜」（食文化）、「民謡の伝播経路」（音楽）、「通過儀礼の類型」（民族文化）等、領域を横断しうる重要概念について調査する。
2. `tpl_doctrine_note.md` の考え方に基づき、対象そのものの解釈と、周辺文化・関連地域による異解釈・変容の対比表を作成する。

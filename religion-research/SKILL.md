# 天理教・分派研究 (religion-research) 専門スキルガイド

本スキルは、天理教の原典、教理、教団史、分派・異端運動（ほんみち、ほんぶしん、太道教、世界心道教等）、および地域拠点（愛町分教会、関東拠点等）に関する学術調査・分析を標準化し、`D:\Vault\religion` Vault 配下に高品質かつ構造化されたObsidianナレッジグラフを構築・維持するための専門ガイドラインである。

> **Vault統合の経緯**：本スキルは元々 `D:\tenri` という天理教専用Vaultを対象としていたが、`D:\tenri` は宗教研究全般を扱う `D:\Vault\religion`（religion-garden）に統合された。天理教関連ノートは旧 `07_分派・異端研究/` のようなフラット構造ではなく、`01_宗派・異端研究/` 配下にテーマ別（教団・人物・概念・ハブ）でシャーディングされている（詳細は下記「Vault構造標準」参照）。

---

## 🧭 基本指針と5大厳守ルール

1. **一次情報主義 (`convMD`)**:
   - 天理教・分派・人物・解説ページ等の一次情報は、必ず `convMD` ツールを用いて `D:\Vault\religion` に直接 Markdown ファイルとして変換・保存する。
   - 実行コマンド例: `uv run python -m convmd.cli "<URL>" --obsidian-vault "D:\Vault\religion"`
2. **客観的・宗教学的研究視点**:
   - 正統・異端の価値判断や宗教的偏見を排除し、歴史的ファクト、警察・裁判資料、文献、教理構造、および宗教学研究（弓山達也・島薗進・井上順孝等の諸説）に基づき客観的に記録・比較する。
3. **Wikilink basename ルールの徹底**:
   - wikilink は必ず **basename 形式** (`[[ほんみち]]`, `[[大西愛治郎]]`) のみを使用し、`[[フルパス/ほんみち.md]]` のような絶対・相対パスは一切使用しない（赤リンク化リスク回避）。
4. **Dataviewブロックの排除（静的Markdown表の強制）**:
   - 公開サイト（Quartz等）での露出エラーを防ぐため、`` ```dataview `` クエリは使用せず、すべて**最初から静的なMarkdown表**として記述する。
5. **留保セクション（`> [!warning]`）とエビデンス明記の必須化**:
   - すべての専門ノートの最末尾に `## 12. 留保（中立的併記・未確定要素）` を設置し、`evidence_type` と `confidence` (1-5) を明記する。

## 📊 10軸徹底教理比較マトリクス基準

正統天理教（親里本部）と分派・異端教団を分析する際は、必ず以下の10評価軸を用いて比較解剖する。

1. **1. 主祭神・神名** （天理王命 / 十柱の神名 vs 独自神名・月読尊/猿田彦等）
2. **2. 核心聖地** （奈良県天理市親里「おぢば」 vs 各教団本部/宝場/精舎）
3. **3. 甘露台（かんろだい）** （物理的木柱構造物 vs 人格的「人間甘露台」/模型）
4. **4. 天啓の継承** （教祖中山みき→本席飯降伊蔵で完結 vs 新たな天啓者自承）
5. **5. 聖典・原典** （『おふでさき』『おさしづ』 vs 独自のお告げ・啓示録追加）
6. **6. 儀礼・つとめ** （かぐらつとめ・九つのお道具 vs 独自て振リ・瞑想・修行）
7. **7. 地方拠点形態** （大教会 / 分教会 vs 宝場 / 精舎 / 支部）
8. **8. 国家・皇室観** （明治期教派神道適応 vs 天皇神性否定・戦前不敬罪弾圧）
9. **9. 救済観・お助け** （八つのほこり・さづけの理 vs 心直し・手かざし・精舎修養）
10. **10. 葬儀・祭祀** （天理教式神葬祭 vs 独自神葬祭/仏式混淆）

## 🛠️ 主なワークフロー

### 1. 新規教団・分派調査・作成
1. Web検索 / 宗教学文献で対象教団の一次情報URLを取得。
2. `convMD` で一次情報を `D:\Vault\religion` に直接Markdown変換取り込み。
3. `D:\Vault\religion\templates\tpl_sect_note.md` の標準12セクション構造に従ってノートを `01_宗派・異端研究\01_天理教系\` に作成。
4. `01_宗派・異端研究\08_比較・史論・ハブ\天理教分派・異端教団一覧.md` および `_天理教ポータル.md` に `[[basename]]` リンクを追加。

### 2. 人物・天啓者調査
1. 天啓者・指導者について調査。
2. `tpl_person_note.md` に基づき12セクションノート化し、所属教団ノートと `[[wikilink]]` で紐付け。

### 3. 教理・概念分析
1. 「甘露台」「おぢば」「おうかん」「三軒三棟」等の重要概念について調査。
2. `tpl_doctrine_note.md` に基づき、正統本部解釈と各分派の異解釈・変容対比表を作成。

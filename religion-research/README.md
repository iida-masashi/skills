# religion-research

天理教、その分派・異端運動（ほんみち、ほんぶしん、太道教等）、教義概念（甘露台、おぢば等）、および歴史的・地域的展開（愛町分教会、東京拠点等）を調査・分析し、`D:\Vault\religion` Vault（宗教研究Vault、旧`D:\tenri`を統合済み）に構造化されたObsidianノートを構築・維持するための高度研究スキル。スクリプトは持たず、指示書（SKILL.md）のみで構成される。

## Vault統合の経緯

本スキルは元々 `D:\tenri` という天理教専用Vaultを対象としていたが、`D:\tenri` は宗教研究全般を扱う `D:\Vault\religion`（religion-garden）に統合された。天理教関連ノートは旧`07_分派・異端研究/`のようなフラット構造ではなく、`01_宗派・異端研究/`配下にテーマ別（教団・人物・概念・ハブ）でシャーディングされている。

## どういう場面で使うか

- 天理教およびその分派・異端教団（ほんみち、ほんぶしん、太道教、世界心道教等）の新規調査・ノート作成
- 天啓者・指導者（中山みき、大西愛治郎、飯降伊蔵等）の人物調査
- 教義概念（甘露台、おぢば、おうかん、三軒三棟等）の教理分析
- 地域拠点（愛町分教会、関東拠点等）に関する歴史的・地域的展開の調査

## 調査対象・原則

- **一次情報主義（`convMD`）**: 一次情報は必ず`convMD`ツールで`D:\Vault\religion`に直接Markdown変換・保存する（`uv run python -m convmd.cli "<URL>" --obsidian-vault "D:\Vault\religion"`）。
- **客観的・宗教学的研究視点**: 正統・異端の価値判断や宗教的偏見を排除し、歴史的ファクト、警察・裁判資料、文献、教理構造、宗教学研究（弓山達也・島薗進・井上順孝等の諸説）に基づき客観的に記録・比較する。
- **Wikilink basenameルールの徹底**: wikilinkは必ずbasename形式（`[[ほんみち]]`）のみを使用し、フルパス・相対パスは使用しない。
- **Dataviewブロックの排除**: 公開サイト（Quartz等）での露出エラーを防ぐため、`dataview`クエリは使わず、すべて静的なMarkdown表として記述する。
- **留保セクションとエビデンス明記の必須化**: すべての専門ノート末尾に「12. 留保（中立的併記・未確定要素）」を設置し、`evidence_type`と`confidence`（1-5）を明記する。

## 標準12セクション構造

`D:\Vault\religion\templates\`配下の各テンプレート（`tpl_sect_note.md`、`tpl_person_note.md`、`tpl_doctrine_note.md`、`tpl_church_note.md`）は、要旨→1.命題の構造→2.基本情報→3.創始者と天啓・社伝→4.沿革・歴史変遷→5.教理・儀礼・神観の深層解剖→6.宗教学的・歴史社会学的意義→7.拠点・現地情報→8.関連教団・関連人物・関連概念→9.史料・一次資料→10.参考文献・学術論文→11.関連ノート→12.留保、の12セクション構造に準拠する。

## 10軸教理比較マトリクス

正統天理教と分派・異端教団を比較する際は、主祭神・神名／核心聖地／甘露台／天啓の継承／聖典・原典／儀礼・つとめ／地方拠点形態／国家・皇室観／救済観・お助け／葬儀・祭祀、の10評価軸を用いる。

## Vault構造標準（`D:\Vault\religion`）

`D:\Vault\religion`は天理教専用ではなく、大本系・世界救世教/真光系・教派神道十三派等も含む宗教研究全般Vault。天理教関連ノートは`01_宗派・異端研究/`配下にテーマ別でシャーディングされる（`01_天理教系/`＝教団・分派・教会、`08_比較・史論・ハブ/`＝分派横断の一覧・比較、`09_人物/`＝人物、`10_概念・原典・事件・拠点/`＝教理概念、`11_実在未確認・要注意/`）。全体ポータルは`_天理教ポータル.md`。

## Highlights

- **スクリプトを持たない指示書型スキル** — Obsidian Vaultへの調査・執筆ガイドラインのみで構成され、実行前提のツールは`convMD`（外部リポジトリ）のみ。
- **5大厳守ルール** — 一次情報主義／客観的視点／wikilink basename／dataview排除／留保セクション必須、を明文化し、公開時のリンク切れやビルドエラーを未然に防ぐ設計。
- **10軸マトリクスによる定型比較** — 正統教団と分派・異端教団を同一の10軸で機械的に比較できるようにし、記述のブレを抑える。
- **旧名からのマイグレーションを明記** — 旧`D:\tenri`（天理教専用Vault）から`D:\Vault\religion`（宗教研究全般Vault）への統合経緯と、フラット構造からシャード構造への変更を本文中で明示。

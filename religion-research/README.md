## 調査対象・原則（5大厳守ルール）

- **一次情報主義（`convMD`）**: 一次情報は必ず`convMD`ツールで`D:\Vault\religion`に直接Markdown変換・保存する（`uv run python -m convmd.cli "<URL>" --obsidian-vault "D:\Vault\religion"`）。
- **客観的・学術的研究視点**: 正統・異端、伝統的・俗流等の価値判断を排除し、歴史的ファクト・文献・学術研究に基づき客観的に記録・比較する。当事者側の論理（emic）と外部観察者側の分析（etic）を区別する。
- **Wikilink basenameルールの徹底**: wikilinkは必ずbasename形式（`[[ほんみち]]`, `[[讃岐うどん]]`）のみを使用し、フルパス・相対パスは使用しない。
- **Dataviewブロックの排除**: 公開サイト（Quartz等）での露出エラーを防ぐため、`dataview`クエリは使わず、すべて静的なMarkdown表として記述する。
- **留保セクションとエビデンス明記の必須化**: すべての専門ノート末尾に「12. 留保（中立的併記・未確定要素）」を設置し、`evidence_type`と`confidence`（1-5）を明記する。

## 共通12セクション構造

領域を問わず、要旨→1.命題の構造→2.基本情報→3.起源と成立の経緯→4.変遷・歴史→5.内容・様式の深層解剖→6.学術的・社会学的意義→7.拠点・現地情報→8.関連対象・関連人物・関連概念→9.史料・一次資料→10.参考文献・学術論文→11.関連ノート→12.留保、の12セクション構造を骨格とする。各`references/<領域>.md`に、領域の実情に合わせた見出し言い換え版がある。

## 領域別比較軸セット

宗教固有だった「10軸教理比較マトリクス」（主祭神・甘露台等）を、領域ごとの比較軸セットに再編した。

- **宗教**: 主祭神・核心聖地・聖典・天啓の継承・儀礼・地方拠点形態・国家観・救済観・葬儀祭祀・系譜関係
- **食文化**: 主要食材・調理法・供される場面・起源伝承・地域内バリエーション・他地域との系譜・担い手の現状・信仰との結びつき・タブー・商業化の程度
- **音楽**: 使用楽器・音階リズム構造・伝承経路・演奏場面・起源伝承・地域内バリエーション・他地域との系譜・担い手の現状・信仰との結びつき・文化財指定
- **土着の民族文化**: 機能・担い手・儀礼手順・象徴と意味づけ・起源伝承・地域内バリエーション・近隣文化との異同・近代化による変容・信仰との結びつき・法制度との関係

## Highlights

- **スクリプトを持たない指示書型スキル** — Obsidian Vaultへの調査・執筆ガイドラインのみで構成され、実行前提のツールは`convMD`（外部リポジトリ）のみ。
- **5大厳守ルール（領域共通）** — 一次情報主義／客観的視点／wikilink basename／dataview排除／留保セクション必須、を明文化し、公開時のリンク切れやビルドエラーを未然に防ぐ設計。
- **共通12セクション構造＋領域別reference** — 宗教で培った構造を骨格として維持しつつ、食文化・音楽・土着民族文化それぞれの調査観点・比較軸・注意点（起源伝承と史実の区別、穴埋め定型文の禁止、エキゾチシズム的記述の禁止等）を独立ファイルに分離。
- **フォルダ新設を先送りする設計** — Vault構造の破壊的変更を避けるため、新領域のフォルダ配置は事前に決め打ちせず、必要になった時点でユーザーと相談する運用にしている。

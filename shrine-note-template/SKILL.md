# shrine-note-template

阿波説 Vault `D:\Vault\awa` で **神社・神格専門ノート** を作成する際の標準テンプレートとガイドライン。

## 適用範囲

| 対象 | 配置先 |
|---|---|
| 阿波国式内社 | `式内社/01_阿波国/01_郡別調査/<郡名>/` |
| 房総（千葉県）式内社 | `式内社/02_安房・上総・下総（千葉）/<旧国名>/` |
| 常陸国・武蔵国 | `式内社/03_常陸・武蔵（北関東）/<旧国名>/` |
| 神格専門ノート | `理論・研究/03_氏族・系譜/神々の系譜/その他の神々・人物/` |
| 系図専門ノート | `理論・研究/03_氏族・系譜/各氏族の研究/<氏族>/` |

## 厳守ルール

1. **wikilinkは basename 形式のみ** — `[[フルパス/X.md]]` は絶対に使わない（赤リンク化リスク）
2. **BOMなしUTF-8** で保存
3. **既存ノートを破壊しない** — 加筆型のみ
4. **過剰一般化を避ける** — 阿波説の解釈と通説を明確に区別
5. **留保セクション必須** — `evidence_type: blog_hypothesis` 等では特に厚く
6. **ファイルサイズ目安** — 5,000〜25,000バイト（テーマの厚みに応じて）
7. **dataview を使わない** — 公開先 Quartz は dataview を描画できず、`` ```dataview `` ブロックは公開サイトで生クエリコードが露出する。「この神を祉る式内社」のような一覧は **最初から静的Markdown表**（旧郡昇順、社名は `[[basename]]`）で書く。`祥序:` 等のクエリ説明文も書かない。詳細・既存ノートの修正手順は [[project_quartz_dataview_static]] 参照

## 神格ノートの場合の追加観点

- **同一神異名群** の整理（平田篤胤「一神異名」説など）
- **複数の系図文献での位置** の比較（粟飯原家系図／斎部宿祢本系帳／高山家本など）
- **后神・夫神・御子神** の系譜
- **後裔氏族** との接続

## 系図ノートの場合の追加観点

- **縦系譜（世代）と横系譜（兄弟・御子）の二軸構造**
- **複数系図の対比表**
- **異名関係の明示**
- **編纂年代と政治的動機**

## 作成後の検証（推奨フロー）

ノート作成後は、専用の使い捨てスクリプトを書かず既存の検証ツールで確認する。

```bash
# 新規ノートの reach（ハブ到達）/ outbound（赤リンク）/ alias衝突 を一括検証
pwsh -NoProfile -Command "& '<vault-verify-notes.ps1のパス>' -Notes @('作成したノートのbasename')"
```

- `vault-verify-notes.ps1` — reach + 赤リンク + alias衝突をまとめて確認（作成直後の定番）
- `vault-orphans.ps1` — 孤立ノート検出（全体スイープ）
- `vault-thin-notes.ps1` — 薄ノート検出
